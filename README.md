# CV Almendralejo · Landing

Landing del Club de Voleibol Almendralejo (HTML + CSS + JS, sin build).

- `index.html` — página completa (estilos y scripts propios).
- `assets/efecto-balon.js` — balón 3D (three.js) que gira y vuela con el scroll.
- `assets/balon.glb` — modelo del balón recoloreado con los colores del club.
- `assets/escudo.png`, `favicon-*.png`, `apple-touch-icon.png` — escudo sin fondo.
- `img/equipo.webp` — foto de la plantilla.

Probar en local: `python -m http.server 8000` y abrir http://localhost:8000 (los módulos ES no funcionan con `file://`).
